Лёгкий юзерскрипт, который дополняет [Letterboxd](https://letterboxd.com/)
внешними рейтингами фильмов, карточками актёров и съёмочной группы,
всплывающими мини-карточками и переводом прямо на странице — сохраняя
привычный вид сайта.

Letterboxd Plus добавляет на страницы фильмов оценки Rotten Tomatoes и
Metacritic, дополняет разделы Cast и Crew портретами, показывает подробные
мини-карточки фильмов и участников, переводит синопсисы, рецензии и
комментарии и предоставляет панель настроек в стиле Letterboxd. API-ключ не
требуется, всё работает в вашем браузере.

Совместим с [Tampermonkey](https://www.tampermonkey.net/),
[Violentmonkey](https://violentmonkey.github.io/),
[Greasemonkey](https://www.greasespot.net/),
[ScriptCat](https://scriptcat.org/) и другими менеджерами, поддерживающими
блок метаданных `// ==UserScript==`.

> **Статус:** `0.23.1`. Доступны рейтинги, расширенные Cast и Crew,
> мини-карточки фильмов и участников, перевод, управление кэшем и интерфейс на
> семи языках. Дальнейшие улучшения Letterboxd добавляются как независимые
> модули.

> `@updateURL` / `@downloadURL` скрипта указывают на ветку `main` в GitHub —
> raw-ссылка ниже всегда ведёт на самую свежую сборку.

## Быстрая установка

1. Установите менеджер юзерскриптов. Рекомендуются Tampermonkey, Violentmonkey
   или ScriptCat.
2. Откройте raw-ссылку на юзерскрипт ниже.
3. Подтвердите установку в менеджере.

**Последняя сборка на GitHub:**

```text
https://raw.githubusercontent.com/NemoKing1210/letterboxd-plus/main/letterboxd-plus.user.js
```

[![Установить Letterboxd Plus](https://img.shields.io/badge/⬇_Install-Letterboxd_Plus-14181c?style=for-the-badge&labelColor=00e054)](https://raw.githubusercontent.com/NemoKing1210/letterboxd-plus/main/letterboxd-plus.user.js)

### Установка из панели менеджера

| Менеджер | Путь установки |
|----------|----------------|
| Tampermonkey | Dashboard → **Utilities** → **Install from URL** |
| Violentmonkey | Dashboard → **+** → **Install from URL** |
| Greasemonkey | Меню дополнения → **New User Script** → вставьте скрипт |
| ScriptCat | Dashboard → установка по URL, затем вставьте raw-ссылку GitHub |

### Ручная установка

1. Откройте
   [`letterboxd-plus.user.js`](https://github.com/NemoKing1210/letterboxd-plus/blob/main/letterboxd-plus.user.js)
   в репозитории (или выполните `npm run build` после клонирования).
2. Скопируйте файл целиком.
3. Создайте новый скрипт в менеджере юзерскриптов.
4. Вставьте файл, сохраните и перезагрузите Letterboxd.

## Возможности

### Внешние рейтинги

На страницах фильмов Letterboxd скрипт добавляет компактные разделы в
нативную боковую панель:

- **Rotten Tomatoes** — рейтинг критиков Tomatometer, статус Certified Fresh
  при наличии, необязательный рейтинг зрителей Popcornmeter, количество
  рецензий и оценок зрителей и прямая ссылка на найденную страницу фильма.
- **Metacritic** — Metascore с количеством рецензий критиков, необязательный
  User Score с количеством оценок, цветовые акценты по диапазону баллов и
  прямая ссылка на найденную страницу фильма.
- **Средний рейтинг** — объединяет рейтинг Letterboxd со всеми включёнными
  доступными внешними оценками. Значения приводятся к пятибалльной шкале
  Letterboxd и усредняются равноправно; недоступные оценки опускаются.

Оба источника используют название фильма и год выпуска для однозначного
выбора результата, а TMDB-идентификатор Letterboxd служит ключом локального
кэша. Скелетоны загрузки и неблокирующие состояния «пусто» и «ошибка»
сохраняют страницу работоспособной, если источник отвечает медленно или
недоступен.

### Расширенные Cast и Crew

Раздел Cast может показывать компактные карточки с портретом, именем и ролью
каждого актёра. Страница Crew получает такое же оформление для режиссёров,
продюсеров, сценаристов и других членов команды.

Портреты читаются с публичных страниц персон Letterboxd только когда карточки
приближаются к экрану, с небольшим ограничением числа запросов. Сначала
показываются первые десять актёров; остальные остаются незагруженными, пока
не выбрано **Show All** и их карточки не приблизятся к экрану. Результаты
хранятся только в памяти.

### Мини-карточки фильмов

При наведении на постер в списках, обзоре, дневнике, watchlist, поиске и
сетках похожих фильмов открывается компактная мини-карточка с:

- постером, названием, годом, рейтингом сообщества Letterboxd и вашим
  статусом (просмотрено, лайк, watchlist, оценка);
- режиссёрами, актёрами, жанрами, слоганом, длительностью и кратким
  синопсисом;
- бейджами Tomatometer и Metascore, если эти источники включены;
- подсказками об уровне рейтинга, быстрыми ссылками и прямой ссылкой на
  страницу фильма;
- кнопкой **Translate** для синопсиса.

Главный постер страницы фильма исключён. Загрузка прогрессивная и
неблокирующая; предзагрузку по видимости можно включить в настройках.
Карточка открывается при наведении или по правому клику — по вашему выбору.

### Мини-карточки участников

При наведении на аватар или ссылку профиля участника в любом месте Letterboxd
открывается мини-карточка с:

- отображаемым именем, ником, аватаром и ссылкой на полный профиль;
- **уровнем и рангом** — шкалой прогресса с очками и следующим рангом;
- статистикой: фильмы, фильмы за год, списки, подписки и подписчики;
- биографией, местоположением, любимыми фильмами и недавней активностью,
  если профиль их публикует.

Карточка не появляется в шапке сайта и внутри других мини-карточек. Как и
карточки фильмов, она открывается при наведении или по правому клику и может
предзагружаться по мере приближения аватаров к экрану.

### Перевод

Встроенный перевод умеет переводить:

- **синопсисы фильмов** на страницах фильмов и в мини-карточках фильмов;
- **рецензии** в карточках рецензий и на отдельных страницах рецензий;
- **комментарии** под рецензиями.

Перевод выполняется на один из семи языков интерфейса или следует языку
интерфейса. Выберите, **заменять** ли оригинал переводом (с переключением
обратно) или показывать перевод **под** ним. Рецензии также могут
переводиться автоматически при прокрутке — по умолчанию выключено.

Перевод использует бесплатный эндпоинт Google — без API-ключа. У каждого
блока своя кнопка Translate, а каждую область можно отключить в настройках.

### Настройки

Откройте **Letterboxd Plus**:

- в выпадающем меню аккаунта Letterboxd сразу после нативного пункта
  **Settings** (выделен фирменным зелёным);
- в меню менеджера юзерскриптов через **Letterboxd Plus settings**.

Доступная панель с вкладками следует визуальному языку Letterboxd и содержит:

- **General** — язык интерфейса и позиция уведомлений;
- **Film** — видимость источников рейтингов, расширенные Cast и Crew,
  поведение и содержимое мини-карточек фильмов;
- **User card** — поведение и содержимое мини-карточек участников;
- **Translation** — язык перевода, режим отображения и области перевода;
- **Cache** — индикатор хранилища, статистика по типам, срок хранения,
  переключатели кэша по источникам и ручная очистка;
- **About** — описание проекта, версия, лицензия, репозиторий и автор.

Диалог поддерживает навигацию по вкладкам с клавиатуры, стрелки, закрытие по
Escape, видимый фокус, мобильные раскладки и режим уменьшенной анимации.

### Языки интерфейса

Интерфейс доступен на семи языках:

- English;
- Русский;
- Español;
- Português (Brasil);
- Deutsch;
- Français;
- 简体中文.

Режим **Auto** по умолчанию проверяет список предпочитаемых языков браузера и
выбирает первый поддерживаемый. Региональные варианты вроде `es-MX`, `pt-PT`
и `zh-Hans` сопоставляются с соответствующей доступной трансляцией.
Неподдерживаемые или отсутствующие локали браузера откатываются к английскому.
Фиксированный язык выбирается в **Settings → General → Interface language**.

### Кэширование и устойчивость

- Успешные ответы Rotten Tomatoes и Metacritic кэшируются в хранилище
  юзерскрипта под отдельными ключами источников.
- Данные мини-карточек фильмов и участников и переводы используют собственные
  ключи кэша, и каждый тип можно отключить на вкладке Cache.
- Срок хранения кэша настраивается от `0` до `168` часов.
- При значении `0` данные всегда запрашиваются заново.
- Вкладка Cache показывает текущее использование относительно осторожного
  ориентира в 5 МБ.
- Активные и истёкшие записи измеряются отдельно и очищаются по типам без
  сброса настроек.
- У запросов фиксированный таймаут, а ошибки никогда не мешают загрузке
  Letterboxd.
- Неудачные запросы и отсутствующие совпадения не сохраняются как успешные
  рейтинги.

## Поддерживаемые страницы

| Сайт | Шаблон URL | Поведение |
|------|------------|-----------|
| Letterboxd | `https://letterboxd.com/*` | Пункт настроек в навигации, рейтинги, Cast и Crew, мини-карточки и перевод |
| Letterboxd (`www`) | `https://www.letterboxd.com/*` | То же поведение для альтернативного хоста |

Рейтинги монтируются только когда страница публикует метаданные фильма через
`body[data-type="film"][data-tmdb-id]`.

## Как это работает

```text
Страница фильма Letterboxd
        │
        ├── чтение названия, года и TMDB ID из метаданных страницы
        │
        ├── проверка кэша в GM-хранилище
        │
        ├── поиск и карточка оценки Rotten Tomatoes
        │
        └── JSON-поиск и карточка фильма Metacritic
                    │
                    ├── строгое совпадение названия и года выпуска
                    ├── чтение оценок критиков и зрителей
                    └── независимое кэширование каждого источника
                                      │
                                      ▼
                            отрисовка в боковой панели Letterboxd
```

Мини-карточки запрашивают публичную страницу фильма или участника Letterboxd
через same-origin запросы браузера и читают уже присутствующие там данные.
Сканер страницы идемпотентен и наблюдает за динамическими изменениями DOM,
поэтому обновления навигации React восстанавливают пункт меню аккаунта и
монтирование функций без дубликатов.

## Источники данных и ограничения

Rotten Tomatoes и Metacritic не предоставляют поддерживаемых публичных API для
этого сценария. Letterboxd Plus читает общедоступные страницы Rotten Tomatoes
и JSON-эндпоинты, используемые сайтом Metacritic, через `GM_xmlhttpRequest`.

Расширенные Cast и Crew читают публичные страницы персон Letterboxd через
same-origin запросы браузера и показывают URL портрета, уже указанный там.
Результаты хранятся только в памяти; биографии и портреты персон не
сохраняются.

Перевод отправляет выбранный текст на публичный эндпоинт Google. Переведённый
текст кэшируется локально в хранилище юзерскрипта, если кэш переводов не
отключён.

Это имеет несколько практических последствий:

- изменения разметки или JSON-схемы источников могут временно нарушить
  извлечение оценок;
- у некоторых новых, малоизвестных или невыпущенных фильмов может не быть
  подходящей страницы;
- фильм может существовать без оценок критиков или зрителей;
- доступность может зависеть от сети или региона.

Такие случаи обрабатываются как снижение функциональности, а не как сбой
страницы Letterboxd. Скрипт не отправляет оценки, не изменяет данные Rotten
Tomatoes или Metacritic и не требует учётных данных.

## Обновления

Метаданные юзерскрипта содержат `@updateURL` и `@downloadURL`, указывающие на
raw-артефакт GitHub в ветке `main`. Совместимые менеджеры могут автоматически
проверять новые выпуски.

Чтобы опубликовать выпуск:

1. Выберите инкремент Semantic Versioning:
   - **major** — несовместимые изменения или миграции;
   - **minor** — обратно совместимые функции;
   - **patch** — исправления, стили, документация и обслуживание.
2. Синхронизируйте версию в `package.json` и `package-lock.json`.
3. Запустите `npm run ci`, чтобы пересобрать и проверить корневые артефакты.
4. Отправьте обновлённый исходный код и сгенерированные файлы.

## Метаданные и разрешения скрипта

| Поле | Значение |
|------|----------|
| `@namespace` | `https://github.com/NemoKing1210/letterboxd-plus` |
| `@match` | Основной и `www`-хосты Letterboxd |
| `@connect` | Хосты Rotten Tomatoes, `backend.metacritic.com` и `translate.googleapis.com` |
| `@run-at` | `document-idle` |
| `@license` | MIT |
| `@updateURL` / `@downloadURL` | Raw-юзерскрипт GitHub в ветке `main` |

| Разрешение | Назначение |
|------------|------------|
| `GM_xmlhttpRequest` | Запросы к внешним источникам рейтингов и перевода |
| `GM_getValue` / `GM_setValue` | Хранение настроек, кэша рейтингов и переводов |
| `GM_listValues` / `GM_deleteValue` | Измерение и очистка записей кэша |
| `GM_addStyle` | Внедрение стилей интерфейса |
| `GM_registerMenuCommand` | Открытие настроек из менеджера юзерскриптов |

Токены доступа, API-ключи, пароли и данные сессии Letterboxd не сохраняются.

## Разработка

Требуется [Node.js 22](https://nodejs.org/), как указано в
[`.nvmrc`](https://github.com/NemoKing1210/letterboxd-plus/blob/main/.nvmrc).

```bash
npm install
npm run dev                # Устанавливаемый юзерскрипт "dev:"
npm run build              # Сборка dist/ и обновление корневых артефактов
npm run verify:artifacts   # Проверка идентичности dist и корневых артефактов
npm run ci                 # Сборка и все проверки репозитория
```

Редактируйте исходники в `src/`. Метаданные юзерскрипта задаются в
[`vite.config.js`](https://github.com/NemoKing1210/letterboxd-plus/blob/main/vite.config.js),
а версия берётся из
[`package.json`](https://github.com/NemoKing1210/letterboxd-plus/blob/main/package.json).

После каждого изменения:

1. обновите версию по Semantic Versioning;
2. запустите `npm run ci`;
3. включите пересобранные артефакты `.user.js` и `.meta.js`.

Не редактируйте минифицированные артефакты вручную и не коммитьте временные
localhost-URL обновлений.

См. также:

- [`AGENTS.md`](https://github.com/NemoKing1210/letterboxd-plus/blob/main/AGENTS.md) — архитектура для AI-агентов
